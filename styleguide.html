Spacing and ownership

Containers own padding and gaps: 4, 8, 16, 24, and 48px. Compose stack and row utilities with appearance primitives; ordinary unclassed HTML retains browser defaults.

Color and typography consume semantic roles. Geometry and ordinary spacing consume primitives directly. Components own configuration; the design system does not own application state.
